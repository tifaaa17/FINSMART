# FINSMART AI

FINSMART AI merupakan aplikasi berbasis website yang membantu pengguna mencatat pemasukan dan pengeluaran serta merencanakan keuangan pribadi. Aplikasi ini menyediakan fitur dashboard, pencatatan transaksi, pengaturan anggaran, target tabungan, dan asisten keuangan berbasis AI.

Aplikasi dibuat menggunakan HTML, CSS, dan JavaScript. Data pengguna dapat disimpan secara lokal melalui browser maupun menggunakan Supabase untuk penyimpanan akun.

## Fitur Aplikasi

- **Dashboard:** Menampilkan ringkasan kondisi keuangan pengguna.
- **Transaksi:** Mencatat pemasukan dan pengeluaran.
- **Anggaran:** Mengatur alokasi dana sesuai kebutuhan.
- **Target Tabungan:** Membuat target dan mencatat perkembangan tabungan.
- **Asisten AI:** Membantu memberikan informasi seputar pengelolaan keuangan.
- **Tema:** Menyediakan pilihan tampilan terang dan gelap.

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
- Supabase
- Google Gemini API

## Cara Menjalankan Aplikasi

1. Download atau clone repository FINSMART AI.
2. Buka folder aplikasi.
3. Jalankan file `index.html` melalui browser.
4. Pilih menu lanjut sebagai tamu atau masuk menggunakan akun.

Untuk menggunakan fitur akun dan asisten AI, diperlukan konfigurasi Supabase dan Gemini terlebih dahulu.
